# Денис Воронков — портфолио и резюме

Один сайт вместо нескольких разрозненных версий: резюме, фирменный стиль, печать, соцсети и сайты. Чистый HTML, CSS и JavaScript — без сборки, фреймворков и сторонних библиотек.

**Адрес:** https://askuyr.github.io/

Оформление: чёрный холст, крупный гротеск Inter Tight, мелкий Inter, волосяные линии, много воздуха. Цвет есть только в самих работах, атмосферные кадры — ч/б.

## Дизайн-система

Всё оформление собрано на токенах в `assets/css/tokens.css`.

| Что | Значение |
|---|---|
| Фон | `#000000`, приподнятые секции `#0A0A0A` |
| Текст | `#FFFFFF`, `#D6D6D6`, `#8E8E8E`, `#6B6B6B` |
| Линии | `rgba(255,255,255,.12)` и `.28` |
| Дисплей | Inter Tight 600–800, uppercase, трекинг −0.02em |
| Текст | Inter 400–600, 14–15 px, интерлиньяж 1.6 |
| Радиусы | 0, только пилюля поиска/резюме — 999 px |
| Тени | нет; глубина создаётся контрастом и пустотой |
| Брейкпоинты | 480 / 768 / 1024 / 1280 |

Тёмная тема — единственная, переключателя нет. Шрифты лежат локально в `assets/fonts`, сторонних запросов нет.

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Для проверки как на сервере:

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000.

## Публикация

Сайт лежит в корне ветки `main` репозитория `askuyr/askuyr.github.io`. GitHub Pages раздаёт его как user pages: https://askuyr.github.io/.

```bash
git add .
git commit -m "site: тёмный редакционный редизайн"
git push origin main
```

## Как править

- Тексты лежат в разметке, каждая секция подписана комментарием `<!-- ================= ... ================= -->`.
- Фильтр работ управляется атрибутом `data-cat` у `.project`: `brand`, `print`, `site`.
- Галерея — ссылки с `data-lightbox` и `data-caption`; порядок листания совпадает с порядком в разметке.
- Выноски на обложке — элементы `.note` внутри `.hero__notes`; координаты задаются классами `.note--a`…`.note--d`.
- Цвета, кегли и отступы меняются в `assets/css/tokens.css`, не в разметке.
- Резюме для скачивания заменяется в `assets/docs/` с теми же именами файлов.

## Принципы

- Никаких вымышленных проектов, метрик и технологий.
- Имена и контакты публикуются только с согласия людей.
- Политическая символика в оформлении не используется.
- Сайт работает без JavaScript: текст, ссылки и картинки остаются доступными.
- Один запрос к сети — только за шрифтами и изображениями самого сайта.
