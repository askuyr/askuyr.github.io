# Денис Воронков — портфолио и резюме

Четыре короткие страницы вместо одного длинного лонгрида: главная, работы, о себе, контакты.
Плюс отдельная страница брендинга. Чистый HTML, CSS и JavaScript — без сборки, фреймворков
и сторонних библиотек.

**Адрес:** https://askuyr.github.io/

Оформление: светлая бумага, глубокий бирюзовый как единственный цвет, крупный узкий
гротеск Oswald в заголовках и антиква Lora в тексте. Первый экран — только типографика:
имя во всю ширину, обрезанное по нижнему краю. Фотографии идут редко и крупно.

## Страницы

| Адрес | Содержание |

## Дизайн-система

Всё оформление собрано на токенах в `assets/css/tokens.css`.

| Что | Значение |
|---|---|
| Бумага | `#F7F9F8`, приподнятые секции `#EBF0EE` |
| Текст | `#06525C` (основной), `#175A64` (второстепенный) |
| Инверсия | поле `#06525C`, текст `#F7F9F8` |
| Дисплей | Oswald 500–600, uppercase, трекинг −0.01…−0.035em |
| Текст | Lora 400 и курсив, 16–26 px, интерлиньяж 1.24–1.6 |
| Кегли | 16 / 19 / 26 / 75 / 88 px и «мега» для имени |
| Радиусы | 0, скруглений нет |
| Тени | нет; глубина — контрастом и пустотой |
| Брейкпоинты | 600 / 820 / 900 px |

Светлая тема — единственная, переключателя нет. Шрифты лежат локально в `assets/fonts`,
сторонних запросов нет. Bebas Neue из референса не взят: в нём нет кириллицы.

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Для проверки как на сервере:

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000.

## Публикация

Сайт лежит в корне ветки `main` репозитория `askuyr/askuyr.github.io`. GitHub Pages
раздаёт его как user pages: https://askuyr.github.io/.

```bash
git add .
git commit -m "site: короткие страницы вместо одного лонгрида"
git push origin main
```

## Как править

- Тексты лежат в разметке, каждая секция подписана комментарием
  `<!-- ================= ... ================= -->`.
- Новая страница копируется с любой существующей: шапка и подвал одинаковые,
  меняется только `<main>` и `<title>`.
- Галерея-просмотр — ссылки с `data-lightbox` и `data-caption`; порядок листания
  совпадает с порядком в разметке.
- Выноски на обложке — элементы `.hero__facts` внутри `.hero__top`; на телефоне имя
  поднимается над ними (порядок задаётся `order` в CSS).
- Плитки работ на главной — `.names`: название в `<h3>` и картинка `.names__thumb`
  (на экранах уже 900 px картинки скрываются).
- Полоса из четырёх картинок на «О себе» и в контактах — `.strip`.
- Цвета, кегли и отступы меняются в `assets/css/tokens.css`, не в разметке.
- Резюме для скачивания заменяется в `assets/docs/` с теми же именами файлов.

## Принципы

- Никаких вымышленных проектов, метрик и технологий.
- Имена и контакты публикуются только с согласия людей.
- Политическая символика в оформлении не используется.
- Сайт работает без JavaScript: текст, ссылки и картинки остаются доступными.
- Один запрос к сети — только за шрифтами и изображениями самого сайта.
