# Денис Воронков — портфолио и резюме

Один сайт вместо нескольких разрозненных версий: резюме, фирменный стиль, печать,
соцсети и сайты. Чистый HTML, CSS и JavaScript — без сборки, фреймворков
и сторонних библиотек.

**Адрес:** https://askuyr.github.io/

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Для проверки как на сервере:

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000.

## Публикация

Сайт лежит в корне ветки `main` репозитория `askuyr/askuyr.github.io`.
GitHub Pages раздаёт его как user pages: https://askuyr.github.io/.

```bash
git add .
git commit -m "site: единое портфолио и резюме"
git push origin main
```

## Как править

- Тексты лежат в разметке, каждая секция подписана комментарием
  `<!-- ================= ... ================= -->`.
- Фильтр работ управляется атрибутом `data-cat` у `.case`:
  `brand`, `print`, `site`.
- Галерея — ссылки с `data-lightbox` и `data-caption`; порядок листания
  совпадает с порядком в разметке.
- Стопка на обложке — карточки `.deck__card` в `#deckStack`; порядок в разметке
  задаёт порядок листания, подпись берётся из `data-title`.
- Цвета, отступы и типографика заданы токенами в начале `assets/css/style.css`
  (`:root`).
- Резюме для скачивания заменяется в `assets/docs/` с теми же именами файлов.

## Тёмная тема

На первом заходе сайт берёт тему из Windows (`prefers-color-scheme`).
Переключатель в шапке меняет тему вручную и запоминает выбор в `localStorage`.
Если выбор не сохранён, смена темы Windows подхватывается на лету.
Разметка темы — атрибут `data-theme="dark"` на `<html>`, стили — блок
`[data-theme="dark"]` в конце `assets/css/style.css`.

- Никаких вымышленных проектов, метрик и технологий.

- Сайт работает без JavaScript: текст, ссылки и картинки остаются доступными.
- Один запрос к сети — только за шрифтами и изображениями самого сайта.
