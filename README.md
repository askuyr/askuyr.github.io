# Денис Воронков — портфолио и резюме

Четыре короткие страницы вместо одного длинного лонгрида: главная, работы, о себе, контакты.
Плюс отдельная страница брендинга. Чистый HTML, CSS и JavaScript — без сборки, фреймворков
и сторонних библиотек.

**Адрес:** https://askuyr.github.io/

Оформление: чёрный холст, крупный гротеск Inter Tight, мелкий Inter, волосяные линии,
много воздуха. Цвет есть только в самих работах, атмосферные кадры — ч/б.

## Страницы

| Адрес | Содержание |
|---|---|
| `index.html` | обложка с портретом и фактами, короткое «о себе», три избранные работы, призыв к контакту |
| `works.html` | пять работ с описанием и ссылками, просмотр картинок крупнее, блок публикаций |
| `about.html` | биография, навыки (включая организацию мероприятий), опыт, образование, политическая и общественная работа, рекомендации |
| `contacts.html` | телефон, почта, GitHub, резюме в PDF и DOCX, копирование почты |
| `branding.html` | брендинг «Нового поколения»: знак в пяти вариантах, палитра, шрифты |
| `404.html` | страница ошибки |

Меню в шапке — три пункта: Работы, О себе, Контакты. Текущая страница отмечена
`aria-current="page"` и подчёркиванием.

## Дизайн-система

Всё оформление собрано на токенах в `assets/css/tokens.css`.

| Что | Значение |
|---|---|
| Фон | `#000000`, приподнятые секции `#0A0A0A` |
| Текст | `#FFFFFF`, `#D6D6D6`, `#8E8E8E`, `#6B6B6B` |
| Линии | `rgba(255,255,255,.12)` и `.28` |
| Дисплей | Inter Tight 600–800, uppercase, трекинг −0.02em |
| Текст | Inter 400–600, 14–15 px, интерлиньяж 1.6 |
| Радиусы | 0, только пилюля «Резюме» — 999 px |
| Тени | нет; глубина создаётся контрастом и пустотой |
| Брейкпоинты | 480 / 768 / 1024 / 1280 |

Тёмная тема — единственная, переключателя нет. Шрифты лежат локально в `assets/fonts`,
сторонних запросов нет.

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Для проверки как на сервере:

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000.

## Публикация

Сайт лежит в корне ветки `main` репозитория `askuyr/askuyr.github.io`. GitHub Pages
раздаёт его как user pages: https://askuyr.github.io/.

```bash
git add .
git commit -m "site: короткие страницы вместо одного лонгрида"
git push origin main
```

## Как править

- Тексты лежат в разметке, каждая секция подписана комментарием
  `<!-- ================= ... ================= -->`.
- Новая страница копируется с любой существующей: шапка и подвал одинаковые,
  меняется только `<main>` и `<title>`.
- Галерея-просмотр — ссылки с `data-lightbox` и `data-caption`; порядок листания
  совпадает с порядком в разметке.
- Выноски на обложке — элементы `.note` внутри `.hero__notes`.
- Цвета, кегли и отступы меняются в `assets/css/tokens.css`, не в разметке.
- Резюме для скачивания заменяется в `assets/docs/` с теми же именами файлов.

## Принципы

- Никаких вымышленных проектов, метрик и технологий.
- Имена и контакты публикуются только с согласия людей.

- Сайт работает без JavaScript: текст, ссылки и картинки остаются доступными.
